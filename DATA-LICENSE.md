# Licença dos dados

A compilação, a normalização e os metadados produzidos pelo projeto são
disponibilizados sob a licença [Creative Commons Atribuição 4.0 Internacional](https://creativecommons.org/licenses/by/4.0/deed.pt-br),
salvo indicação diferente no manifesto de uma fonte.

Os documentos legislativos subjacentes continuam sujeitos aos termos de suas
fontes oficiais. Cada release inclui a URL, a atribuição e o status de
redistribuição de cada fonte. Fontes com status `pending` ou `blocked` não
podem integrar um release público; `metadata_only` permite somente metadados e
links para o documento oficial.
